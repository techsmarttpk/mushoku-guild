# Mushoku Guild 0.3.0

- **Context control** on quests, Guild Chat and Universal Chat: No Context, Project Capsule, Relevant Context, Deep Research (the only mode that starts Claude Code). Size estimate shown before sending; budgets configurable in the Guild tab.
- **OpenRouter, free models only:** connect with an API key (stored in Windows Credential Manager), browse and test eligible free models, recruit them from the Guild tab with the rectangular + button.
- **Guild members in the café:** every recruited model is a procedurally generated pixel character with its own look and activity; click one to chat, inspect or remove it.
- **Universal Chat** can talk to any recruited model; each conversation is tied to its exact model.
- Existing ChatGPT and Claude integrations and all user data are unchanged (database migration 6 preserves Universal Chat history).
