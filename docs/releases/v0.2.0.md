# Mushoku Guild 0.2.0

Cycles 5 and 6 on top of 0.1.0.

- **Café stability:** the random black café canvas is fixed. Causes addressed: a canvas discarded while hidden/minimised/behind the Library tab was never redrawn (the frame-skip check thought nothing had changed); no handling of WebGL context loss; a throwing frame stopped the animation chain. Now: forced redraw on resume, tab change, focus and resize; context loss and restore handling; guarded draws; at most one Pixi application per scene; automatic rebuild of only the scene (bounded), then a "Retry rendering" fallback; diagnostics in `CafeScene.diagnostics()`.
- **Idle conversations:** Reasoner and Executor chat now and then from a local, hand-written collection (time of day, quest outcome, quiet board), with cooldowns and repetition avoidance. No AI calls.
- **To-Do tab:** personal tasks (priority, due date, description, optional repository tag, search, filters, sorting, progress). Not quests; never starts an AI run.
- **Library:** search is a button on the shelf (field opens on demand); the shelf now adapts to the window size.
- **Research:** `docs/MULTI_MODEL_PROVIDER_RESEARCH.md` (nothing implemented).
- Also in this release: four-daypart café atmosphere, quest attachments, Universal Chat (Cycle 5).
