# Mushoku Guild 0.1.0

**Release date:** 2026-11-09 · **Platform:** Windows 10/11 x64 · **Signing:** not code-signed

First packaged release. Everything below was exercised in the running app; what was not is listed under limitations.

## Highlights

- Pixel-art café with a Reasoner (ChatGPT) and an Executor (Claude Code); quests, speech bubbles, activity.
- Repository-centric workspaces: conversations, quests, permissions, library and editor tabs per repository.
- Quests with ChatGPT-engineered prompts, Claude Code execution, per-repository trust, three policies, optional Auto Pilot, searchable history.
- Guild Chat with saved conversations and autonomous, read-only repository research by Claude.
- Repo tab: native explorer, CodeMirror 6 editor, full Git workbench with a lane-based graph, output panel.
- Library bookshelf with Markdown and Mermaid rendering.
- Launched-service tracking and optional Claude in Chrome.

## Install

1. Download `Mushoku-Guild_0.1.0_windows-x64_setup.exe` and check its SHA-256 (below).
2. Run it. Windows SmartScreen may warn because the installer is unsigned: *More info → Run anyway*.
3. Install the Claude Code CLI and Git separately; sign in to Claude Code once in a terminal.

Full instructions: `docs/INSTALLATION.md`. Uninstalling keeps your data (`%APPDATA%\com.techsmarttpk.mushokuguild\`).

## Known limitations

- Unsigned installer and executable; no auto-update; Windows only.
- ChatGPT sign-in is experimental and may stop working; subscription-terms questions are unresolved.
- No interactive terminal, no three-way merge editor, no OS file watcher (3 s polling).
- No license has been chosen yet (all rights reserved by default).
- Full list: `docs/KNOWN_LIMITATIONS.md`.
