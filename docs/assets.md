# Asset and licence inventory

Status: **implemented** (Phase 3, 2026-11-08). Update this file whenever an asset or runtime resource is added.

## Art
| Asset | Origin | Licence |
|-------|--------|---------|
| Café interior (walls, floor, rug, furniture, windows, quest board, props) | **Original.** Drawn by code in `src/cafe/world.ts` onto 2D canvases at start-up (palette in `src/cafe/pixel.ts`). | Project's own work (project licence still to be chosen, `docs/context.md` §15.2) |
| Reasoner and Executor characters, speech bubbles, quest tickets | **Original.** Generated by code in `src/cafe/sprites.ts`. | Same |
| In-world pixel font (3x5 glyphs) | **Original**, `src/cafe/pixel.ts`. | Same |

No Pokémon or other third-party sprites, maps, logos or proprietary assets are used. The style (top-down, warm wooden interior, small sprites, limited palette) is inspired by early handheld RPGs only in general terms.

### Why generated art
Kenney's asset pages (CC0) refused scripted downloads (HTTP 403 to non-browser clients). I did not spoof a browser identity to get around that. No other pack was mixed in, because a single consistent style matters more than polish from mismatched sources. If you would like Kenney's CC0 packs or hand-drawn sprites used instead, download them in a browser into `src/assets/` and tell me; the scene code only needs textures per pose.
